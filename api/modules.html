API Reference#

Every solver comes in a sequential form, which uses a Riccati recursion and suits CPUs, and a parallel form, which uses an associative scan with \(O(\log T)\) depth and suits GPUs on long horizons. Each also has a differentiable wrapper. The wrapper returns \(\tau = [x_t, u_t]\) and has implicit (adjoint-LQR) gradients with respect to the problem parameters.
