LQR (parallel)#

LQR solver using associative parallel scan [Särkkä & García-Fernández, 2023, arXiv:2104.03186].

The value functions are found with an associative scan over conditional value function elements, and the optimal trajectory with an associative scan over the closed-loop affine dynamics. The cross term S and the linear input cost r are removed first by the change of variables u = ũ - G x - g, with G = R⁻¹Sᵀ and g = R⁻¹r, which leaves an equivalent problem with S = 0, r = 0.

diffilqrax.plqr.regularise_lqr(lqr, mu)[source]#

Levenberg-Marquardt regularisation in input space, R -> R + μI, i.e. a proximal cost ½μ‖u‖² on the input step. Unlike a regulariser applied to Huu during the Riccati recursion, it does not depend on the value function, so the regularised problem is still an LQR and the associative scan solves it exactly. In the Riccati recursion it adds μI to every Huu.

Parameters:

  • lqr (LQR) – LQR parameters.

  • mu (float) – Regularisation strength.

Returns:

Regularised LQR parameters.

Return type:

LQR

diffilqrax.plqr.project_psd_lqr(lqr, delta=1e-06, which='full')[source]#

Convexify the local LQR stage by stage. R is projected to eigenvalues ≥ δ and, if which == "full", the Schur complement Q - S R⁻¹Sᵀ and Qf too. The fully projected problem is a strictly convex LQR, so every element of the associative scan is valid and every Huu is positive definite without retries. Linear terms are untouched, so the gradient of the local problem is unchanged, but it is no longer a Newton model where the projection is active. With which == "R" only negative input curvature is removed: the projection is inactive wherever R ≻ δI, where the Newton step is kept.

Parameters:

  • lqr (LQR) – LQR parameters.

  • delta (float) – Minimum eigenvalue after projection.

  • which (str) – “R” to project R only, “full” to also project Q - S R⁻¹Sᵀ and Qf.

Returns:

Convexified LQR parameters.

Return type:

LQR

diffilqrax.plqr.plqr_backward_pass(model, mu=0.0, pd_thresh=1e-08, return_values=False)[source]#

Parallel counterpart of diffilqrax.lqr.regularised_backward_pass(): associative Riccati scan of the problem regularised with regularise_lqr(), and its optimal gains.

Parameters:

  • model (LQRParams) – LQR model parameters.

  • mu (float) – Regularisation strength, by default 0.0 (exact LQR solution).

  • pd_thresh (float) – Minimum eigenvalue of the regularised Huu for it to count as positive definite, by default 1e-8.

  • return_values (bool) – Also return the value functions (η, J) of the regularised problem, by default False.

Returns:

Expected change in cost terms (V: Σ ½ kᵀ Huu k with the unregularised Huu, v: Σ kᵀ hu), the gains (u = Kx + k), and a flag that is True if the regularised Huu is positive definite at every time step and the gains are finite. With return_values, also (η, J) [(T+1)xn], [(T+1)xnxn], whose costates λ_t = J_t x_t - η_t are the multipliers of the regularised problem.

Return type:

Tuple
